# DVD Rental SQL Analysis

## Project Overview

This project uses PostgreSQL to analyze the DVD Rental database. The analysis explores films, customers, addresses, rentals, and customer payments.

## Business Questions

1. What are the 10 most expensive films to rent?
2. Which films have a rental rate greater than $4.00?
3. How many films are available in each rating category?
4. Which customers live in California?
5. Who are the five highest-spending customers?

## SQL Skills Demonstrated

- SELECT statements

- WHERE filtering
- ORDER BY sorting
- Aggregate functions
- GROUP BY

- LIMIT
- PostgreSQL functions
